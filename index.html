隐私政策

我们非常重视您的隐私。请在使用"压缩解压专家"（以下简称"本应用"）前仔细阅读本政策。使用本应用即表示您同意本政策的内容。

一、我们不收集任何数据

  • 本应用不收集、不存储、不上传任何个人数据，包括但不限于：您的文件内容、文件列表、设备信息、位置信息、通讯录、使用统计。
  • 本应用不包含广告 SDK、统计分析 SDK、崩溃上报 SDK 或任何第三方数据采集组件。
  • 本应用不申请网络访问权限（Manifest 中无 INTERNET 权限），技术上无法将您的任何数据发送到网络。

二、文件访问权限的使用

本应用是一款本地文件压缩、解压与文件管理工具，文件的压缩、解压、浏览、删除等操作均在您的设备本地完成：

  • SAF 目录授权（默认模式）：通过系统文件选择器授权特定目录，无需任何敏感权限。
  • 所有文件访问权限（MANAGE_EXTERNAL_STORAGE，可选）：用于浏览和管理设备共享存储中的全部文件与文件夹，这是文件管理器类应用的核心功能。您可以在系统设置中随时撤销该权限，撤销后应用自动回退到 SAF 模式，核心功能不受影响。
  • 前台服务与通知：执行大文件压缩/解压任务时使用前台服务并显示进度通知，任务可在您离开界面后继续进行，可随时取消。

您的文件仅用于您在应用内主动发起的操作（压缩、解压、查看、删除、分享），我们无法访问，也不会传输到任何服务器。

三、本地数据存储

本应用仅在设备本地存储以下轻量偏好设置（通过 Android DataStore 实现）：您选择的主题模式（浅色/深色/跟随系统）、您通过 SAF 授权的目录凭证。卸载应用即彻底删除。

四、儿童隐私

本应用不面向 13 岁以下儿童进行营销，也不故意收集儿童的任何个人信息（本应用本身即不收集任何信息）。

五、政策变更

若应用功能发生重大变化导致本政策更新，我们将在本页面发布新版本并更新"更新日期"。

六、联系我们

Privacy Policy

App: Compress & Unzip (压缩解压专家) ｜ Package: com.archivemaster.app ｜ Last updated: 2026-10-02

Your privacy matters to us. Please read this policy carefully before using "Compress & Unzip" (the "App"). By using the App you agree to this policy.

1. We do not collect any data

  • The App does not collect, store or upload any personal data, including but not limited to: your file contents, file lists, device information, location, contacts, or usage statistics.
  • The App contains no advertising SDK, analytics SDK, crash-reporting SDK or any third-party data-collection component.
  • The App does not request network access (no INTERNET permission in the manifest) — it is technically impossible for the App to send any of your data over the network.

2. Use of file access permissions

The App is a local file compression, extraction and file management tool. All operations run locally on your device:

  • SAF folder authorization (default): you grant access to specific folders via the system file picker — no sensitive permissions required.
  • All-Files-Access (MANAGE_EXTERNAL_STORAGE, optional): used solely for browsing and managing all files and folders on shared storage, which is the core function of a file manager. You may revoke this permission anytime in system settings; the App then automatically falls back to SAF mode without losing core functionality.
  • Foreground service & notifications: long compression/extraction tasks run in a foreground service with a progress notification you can cancel at any time.

Your files are only used for actions you initiate inside the App (compress, extract, view, delete, share). We have no access to them and never transmit them to any server.

3. Local storage

The App stores only lightweight preferences locally on the device (via Android DataStore): your chosen theme (light/dark/system) and the SAF directory grant you authorized. Uninstalling the App removes everything.

4. Children's privacy

The App is not directed at children under 13 and does not knowingly collect any personal information from children (the App collects no information at all).

5. Changes to this policy

If a major app change requires updating this policy, we will publish the new version on this page and update the "Last updated" date.

6. Contact us
